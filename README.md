# The Funniest Office Joke

An entry for the make.fun contest "The Funniest Office Joke, Judged Head to Head".
The whole entry is one short line about office life: an out-of-office reply set to
the most passive-aggressive sentence in corporate email — "Per my last email" —
so its owner stays undefeated in every workplace argument even while on vacation.

## Run

```sh
python3 main.py
```

This writes the joke (120 characters, UTF-8) to `/output/entry.txt`, creating the
`/output` directory first if it does not exist.
